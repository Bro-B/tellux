TelluxThree.js 3D Earth Engine

面向数字地球、数字孪生、三维地图及各类 3D Earth 应用的 TypeScript API。

查看 Viewer API

地球与相机

使用经纬高、heading、pitch、roll 组织视角，并提供飞行定位、拾取和高度采样能力。

地形、影像和 3D Tiles

支持 Cesium quantized-mesh terrain、XYZ、WMS、WMTS、GeoJSON、MVT 和独立 3D Tiles 场景。

大气、云和后处理

集成 Takram geospatial 生态中的大气、体积云、光照和后处理效果。

文档定位 ​

Tellux 文档面向库使用者，提供从初始化 Viewer 到加载真实地理数据的完整路径。

  • 指南 解释常见工作流和推荐写法，建议按「快速开始 → Viewer 基础 → 相机控制 → 交互与拾取 → 地形与影像 → 3D Tiles → 实体绘制 → 坐标系与自定义对象 → 光照 → 大气效果 → 数据源」的顺序阅读。
  • API 文档 记录公开 TypeScript API 的参数、返回值和生命周期。
  • 能力参考 汇总底层依赖能力，帮助判断 Tellux 当前封装到什么程度。
  • 能力边界 集中说明当前版本的限制和不支持的场景，选型和排查前建议先看。
